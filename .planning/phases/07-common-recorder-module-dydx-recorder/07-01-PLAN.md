<objective>
Extract the exchange-agnostic recorder machinery (RecorderStrategy + RecorderStrategyConfig, plus the shared path-resolution / streaming-config helpers) out of scripts/bybit_recorder/ into a new scripts/common_recorder/ module, then re-point scripts/bybit_recorder/ at it with ZERO behavior change. This delivers DYDX-01 and is the gating prerequisite for every dYdX plan in this phase.

Purpose: A second venue (dYdX) must reuse the proven recorder infra without forking it. The strategy is already ~95% venue-agnostic; the only coupling to resolve is _on_config_reload's direct import of the venue config loader, which becomes an injected callable (set_config_loader) so the common module never imports a venue package.

Output: scripts/common_recorder/{__init__.py, strategy.py, config.py}; rewritten scripts/bybit_recorder/{strategy.py, config.py} as re-export shims (config.py keeps its Bybit-specific parsing); scripts/bybit_recorder/recorder.py wires the injected loader. The existing 62-test recorder suite is the no-behavior-change gate.
</objective>
