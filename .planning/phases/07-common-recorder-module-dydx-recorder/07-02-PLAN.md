<objective>
Build the dYdX recorder's config layer: scripts/dydx_recorder/config.py parses a flat perpetual instrument list (no linear/spot split, no depth knob — dYdX is full-depth L2), validates each configured bar interval against the supported dYdX resolution set with a fail-fast error (DYDX-06), maps the environment string to DydxNetwork case-insensitively, and reuses the common_recorder shared helpers. Ships with an example recorder.toml carrying the DYDX-05 relaxed-quote / tight-deltas thresholds, and a unit-test file covering interval whitelist, threshold parsing, network round-trip, and id validation (DYDX-02 / DYDX-05 / DYDX-06).

Purpose: dYdX's config shape differs from Bybit's (flat perps, no depth, interval whitelist instead of depth whitelist), so it needs its own parser — but it shares the path-resolution / streaming / threshold-validation helpers extracted in Plan 01. Fail-fast interval validation prevents an unsupported resolution crashing the node at subscribe time (DYDX-06).

Output: scripts/dydx_recorder/{__init__.py, config.py, recorder.toml}; tests/unit_tests/persistence/recorder/test_dydx_recorder_config.py.
</objective>
