<objective>
Make the live metrics layer compute and propagate every ranked metric the upgraded
dashboard needs. Today `_metrics_from_rolling()` returns only OFI/OBI/microprice/spread,
and `_fast_loop` then drops everything except ofi/microprice/spread when updating an
existing `_LIVE` entry. This plan extends the metric computation with CVD, volume delta,
buy/sell count, avg trade size, and microprice lean (per DASH-01), and fixes the write
path so all fields reach `_LIVE` every second.

Purpose: DASH-01 requires the rankings table to show OFI_10, OBI_10, CVD, spread,
microprice lean, volume delta, and buy/sell count. None of those (beyond ofi/spread)
currently survive the `_fast_loop` write. Without this, the table columns added in plan
02 would render `—` forever.
Output: Extended `_metrics_from_rolling()`, fixed `_fast_loop`, and a new test file
covering the new financial calculations.
</objective>
