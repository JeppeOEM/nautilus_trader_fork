<objective>
Make the recorder survive an unattended SIGTERM stop without losing recent data, and lock in that reconnect is fully adapter-owned.

This plan refactors the existing periodic conversion body into a shared `_run_conversion()` method and adds an `on_stop()` override that runs a final flush + per-type convert while the kernel `"*"` StreamingFeatherWriter's feather files are still on disk (REL-02). It also locks in REL-04 (adapter-driven reconnect) with a structural "no reconnect code" assertion and a manual forced-disconnect / stop-then-start proof.

Purpose: A `Restart=always` systemd loop drives SIGTERM on every stop/restart; the recorder must flush/convert the un-converted feather tail before exit so the next process starts clean. Reconnect must NOT be hand-rolled (REL-04) — the Bybit Rust WS client already handles exp-backoff reconnect + `resubscribe_all()`.
Output: `on_stop()` + `_run_conversion()` in `strategy.py`; unit tests for the on_stop convert path; an explicit restart-shaped conversion regression test; a manual integration checkpoint proving forced-disconnect resume and same-day stop-then-start no-loss.
</objective>
