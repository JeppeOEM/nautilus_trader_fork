- (decision) AD: Bad-data handling. When the collector detects an invariant violation (crossed book, stale feed beyond _STALE_BOOK_NS, or any future validation failure), the offending data is dropped -- never written to Parquet, never published to Redis -- and a WARNING-level log line records the full offending payload plus the specific reason. No validity-flag field is added to any schema; log lines (visible via the existing Dozzle container) are the sole audit trail. User-confirmed: write the bad data to the log so it can be inspected and also write in log what went wrong.
- (decision) AD: Readers never validate. - (constraint) [ADOPTED] No TradingNode/Strategy/DataEngine runtime inside troll/ -- collector owns its own asyncio loop, in-memory buffer, and flush timer, calling nautilus_pyo3 DydxHttpClient/DydxWebSocketClient directly. Reason: live DataEngine has a documented unbounded-queue-growth + shutdown-wedge bug under sustained high-message-load that OOM-crashed an earlier Strategy/TradingNode-based recorder (gg branch).
- (constraint) [ADOPTED] Precision integrity: never use Price(decimal, precision) / Quantity(decimal, precision) to re-stamp a value's precision -- silently corrupts some inputs via internal float64 round-trip (e.g. Price(Decimal('61090.59855'), 16) -> 61090.5985500000026624). Always Decimal.scaleb(new_precision) + Price.from_raw()/Quantity.from_raw(). Never derive precision from digit count (Decimal.normalize()) -- dYdX's mark/index feed strips trailing zeros inconsistently per tick. Never round-trip a market value through float before it is inside a Price/Quantity.
- (constraint) [ADOPTED] All catalog writes go through ParquetDataCatalog.write_data() only -- no hand-rolled Parquet schema, ever. Backtests use BacktestNode + BacktestDataConfig (streamed, time-bounded), never a custom simulation loop or an unbounded catalog.trade_ticks() call. Strategies referenced via ImportableStrategyConfig by string path.
- (constraint) [ADOPTED] Liquidity classification uses volume24H (USD) or openInterest x oraclePrice -- never raw openInterest (base-token units) against a USD threshold. Production incident: BTC at 458 tokens OI failed a >=100000 USD threshold naively.
- (constraint) [ADOPTED] Deployment/operational envelope: two-image Docker split -- nautilus-trader-base:1.229.0 (rebuilt rarely, core/deps only) + troll/collector.dockerfile thin layer (bakes in dydx_collector/ + ml_signals/, rebuilds in seconds).
