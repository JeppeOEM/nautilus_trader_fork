Coins-pane staleness is pane-level, tied to the shared ranking_engine heartbeat (EXPERIENCE.md Data Sources & Staleness) — when it fires every row goes stale together, never a single row alone (that per-row independence is the Bots pane's own, separate signal). Shown abbreviated to 3 rows here; production renders all rows this way. Last-known ranks stay visible, never silently frozen.
