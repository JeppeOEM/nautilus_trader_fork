Coin detail

Full-screen replace from a Coins-pane row (Enter). Live indicators computed via ml_signals.indicators (never re-derived locally). The order-book region opens collapsed to top-of-book only by default — d toggles it open to the full depth ladder (up to 20 levels/side, bid left / ask right, fixed column position per DESIGN.md's Accessibility Floor). Full depth is always reachable, never removed — just not the default rendering (clarifies FR-20's "never truncated to top-of-book only" as a capability guarantee, not a default-open mandate).
