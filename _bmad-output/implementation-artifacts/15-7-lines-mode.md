# Story 15.7: Lines mode

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As the dashboard operator,
I want to switch a coin's chart from candlesticks to a direct line comparison of bid/ask/mid/microprice/price,
so that I can read raw price-series behavior the way I do today, without losing my place in time when I switch.

## Acceptance Criteria

1. **`dashboard.py`'s existing Candles/Lines toggle is carried forward on the chart page.** This is `_render_chart_page`'s `#btn-candles`/`#btn-lines` pair (`ml_signals/dashboard.py:1330-1336`) — a two-button mode switch, not a checkbox/dropdown.
2. **`GET /api/snapshots/{instrument_id}` accepts `before_ns` + `limit` and returns `{"items": [...], "has_more": bool}` under the identical cursor-paginated contract as `/api/candles`** (spine AD-F3 explicitly binds `/api/snapshots` by name, not just `/api/candles` — an earlier spine draft naming only `/api/candles` was itself flagged as a bug). `data_api/routes/snapshots.py` is a new file, per the architecture spine's Structural Seed.
3. **Switching from Candles to Lines mode (or back) preserves the currently-viewed time range — it is never reset to a default window** (FR-43).
4. **A gap in the underlying snapshot data renders with the same AD-F6 gap-marker discipline as Story 15.3's candles** — never an interpolated flat line.
5. **Tests:** the same boundary/pagination test pattern Story 15.3 applied to `/api/candles` is applied to `/api/snapshots` (TEST-01, mirrors Story 15.3's coverage).
