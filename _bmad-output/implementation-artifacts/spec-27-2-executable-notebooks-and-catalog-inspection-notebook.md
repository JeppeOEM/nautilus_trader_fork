## Intent

**Problem:** Research notebooks are unreviewable `.ipynb` blobs that nothing executes, so they rot silently after refactors (three legacy ones already do); and there is no single place that shows what the archive actually holds per venue — coverage, gaps vs quiet market, verified days, trade-fold agreement, snapshot sanity and ledger rejections — before a research result is trusted.

**Approach:** Make every numbered notebook a jupytext percent-format `.py` (source of truth, ruff/mypy-clean) paired with an output-stripped `.ipynb`, parameterised from env vars through one `_params.py`, and executed by `research/tests/test_notebooks.py` with `runpy` against one session fixture catalog (3 venues × 2 instruments, planted defects). Ship `01_catalog_inspection` whose every number comes from a new `research/application/inspection.py` service over bounded reads (`MarketFrames`, `archive.application.diagnostics` gap heuristics, the candle store's day status, `kernel.fold.fold_trades`, the 23.3 ledger readers); delete `dydx_catalog_pandas.ipynb`.

## Boundaries & Constraints

**Always:**
- Every market-data read bounded by `START`/`END` (MEM-01); the notebook calls only `CatalogFrames` methods (all keyword `start=`/`end=`), `inspection` functions and plotly — no formula, groupby-arithmetic or fold in a cell (epic: notebooks hold no analysis logic).
- Gaps and defects stay visible: crossed/missing seconds are NaN in every plotted series, never filled; a fold mismatch or precision disagreement is printed, never dropped (DATA-01/DATA-07).
- Exact comparisons for the fold agreement: per second, `fold_trades(...).snapshot_values()` vs the snapshot's stored trade columns, equality (NaN == NaN for empty OHLC); no float tolerance.
- Fixture writes only through `ParquetDataCatalog.write_data()`, real Nautilus objects, `Price`/`Quantity` built from strings/raw (never float before `Price`); snapshots' trade columns generated by `fold_trades` from the fixture's own ticks.
- New cross-context reach is allowlisted in `platform/tests/test_boundaries.py` with a stated reason and a "still used" check, and recorded in the DDD spine AD-D2 with an `[amended 2026-09-28: Story 27.2]` note.
- LGPL header on every new `.py` (not on `.ipynb`), full type hints, ruff line length 100, one import per line.

**Block If:**
- The notebook cannot run under `warnings.simplefilter("error")` without filtering a warning raised by `nautilus_trader`/pandas/plotly internals that our code cannot avoid.

**Never:**
- No new package: `jupytext` is already locked (`uv.lock` 1.19.3, dev group); adding it to `platform/requirements.txt` so the collector image `make test` runs in has it is an install of a locked dependency, not a new one. No `nbclient`/`papermill`/`kaleido`, no Jupyter compose service.
- No edit under `nautilus_trader/` or `crates/`. No research import of `views`, `ranking` or `data_api` (tests included). Never write `sprint-status.yaml`.
- No unbounded `likely_outages`/`coverage` call from research (they read whole data types).

## Design Notes

- **metrics.db deviation (AC #2):** the fixture writes no `metrics.db`. `research/tests` may not import `ranking` (`test_research_imports_no_views_or_ranking` covers test modules), and since 27.1 no research code reads `metrics.db` (`RankingHistory` is HTTP); `METRICS_DB_PATH` stays in `Params` per AC #1 for the notebook that first needs ranking context, which seeds data over HTTP as `test_ranking_history.py` does.
- **research → archive edge:** gap/outage heuristics have one home (`archive.application.diagnostics`, Story 25.1); research calls only the pure functions over its own bounded timestamps, never the unbounded catalog readers.
- **Outage vs quiet (amended in review):** every seconds gap (`find_gaps`) is one row, classified whole by the mark stream over it: `likely outage` when the longest mark silence inside it is at least half the gap (marks resume a little before the book after a reconnect), `book gap` when marks kept flowing, `no mark coverage` when marks do not bracket it (Bybit spot, a feed that ended). Intersecting each stream's own-threshold gaps (the first cut) mislabelled sparse-mark outages and mark-less instruments. `quiet market` = trade gap overlapping no seconds gap; one that overlaps is attributed to it (Known limit). Gaps below the 30 s floor are not flagged.
- **Fold agreement on provisional days:** live seconds fold by arrival, so a not-yet-rebuilt day may disagree at second granularity; the notebook prints day status beside the verdict, never hides the row.
- **License header in notebooks:** a leading `# %% [raw]` cell (jupytext turns a leading comment block into a code cell, which would displace Parameters as the first code cell).
- **Runner cwd:** Jupyter starts the kernel in `research/notebooks/`; the test prepends that directory to `sys.path`, so `from _params import Params` (sorted first among third-party imports) runs before any platform import in both.
